# Break Reminder

Shows a popup reminding you to take a break after you have been playing for a while.

- Set the interval in the mod settings (1 to 180 minutes).
- Idle time doesn't count: the game must be the active window and you must be using the keyboard or mouse (Windows).
- While you are inside a level, the popup waits until you complete the level, die (the game pauses on respawn) or pause, so it never interrupts a run.
- A button on the main menu (top right) shows how long you have played today. The total is saved between sessions and resets at midnight.
- The popup title and message can be customized, and the mod has English and Spanish texts.
- The popup has a **Snooze 5 min** button.
